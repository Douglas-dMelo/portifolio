## 🚀 Projeto em destaque

### 💈 Sistema de Agendamento — Barbearia

Sistema web desenvolvido para uma barbearia, permitindo agendamento online
de serviços com escolha de data e horário, além de confirmação automática
via WhatsApp.

**Tecnologias utilizadas:**
- HTML5
- CSS3
- JavaScript (Vanilla)
